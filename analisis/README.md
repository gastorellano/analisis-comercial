# Análisis 
Esta carpeta contiene los archivos utilizados para desarrollar el análisis de datos. 
El archivo principal es: 
`analisis.ipynb` 
En un proyecto real, el notebook podría incluir: 
- exploración de los datos; 
- limpieza; 
- transformaciones; 
- cálculos; 
- agrupaciones; 
- visualizaciones; 
- conclusiones.
